Module spotlight

The coding agent works in your actual repo.

Connect a GitHub repository once, and the agent reads, edits, and runs code with real terminal access — not a sandboxed toy that forgets the codebase between messages.

  • Reads and edits real files across the connected repo
  • Runs commands in an actual terminal session
  • Opens commits and pull requests through GitHub OAuth
  • Session carries over from your SanjayAIHub login automatically
Try the coding agent
$ connect github.com/you/your-repo
→ repo linked, branch main
agent> fix the failing FK constraint in chat threads
→ reading modules/chatbot.js
→ reading routes/chat.js
→ patch applied, tests running
Getting set up

From signup to your first generation, in three steps.

01

Create your account

Every plan starts with a 7-day trial — no card required. Chatbot, prompt library, and several other modules are free from the first minute.

02

Add your provider keys

Drop your NVIDIA, Alibaba Cloud, ElevenLabs, Cloudflare, or Pixazo keys into Profile → API Keys. They stay yours, stored per-account.

03

Switch modules, not tabs

Move between chat, image, video, voice, and code from the same session, with usage billed by your provider — not marked up by us.
